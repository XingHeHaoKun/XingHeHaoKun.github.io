010 Editor：把文件拆开看

010 Editor 是我最常开的窗口。它本质上是个十六进制编辑器，但真正值钱的是两个功能：

  • Binary Templates：加载模板后能把文件按结构高亮成字段（PNG 的 chunk、ZIP 的中央目录、PE 的头），一眼看出哪块被改过；
  • Compare / 编辑：两个相似文件对比差异，或者直接改某个字节另存。

典型用法：Misc 题里 PNG 常被改掉 IHDR 宽高或 tEXt 长度导致打不开。用 010 打开，对照模板找到 IHDR 之后的宽高四字节，改回真实尺寸即可。改完记得同步修正对应 chunk 的 CRC（或者干脆用脚本重算）。

修文件头是 Misc 的低成本得分点：把前 8 个字节改成正确魔数，往往就能让工具重新识别文件。

Strings：最暴力的第一步

Sysinternals 的 strings.exe（或 GNU strings）从任意二进制里抠出可打印字符。别看它土，命中率极高——flag 藏在注释里、藏在拼接进图片的文本里，全靠它第一遍扫出来。

:: 只要长度 >= 6 的字符串
strings.exe -n 6 flag.zip

:: 大端/小端宽字符（UTF-16）也要扫，Windows 程序常这样存
strings.exe -n 6 -e l file.bin

:: 直接筛 flag
strings.exe -n 4 image.png | findstr /i "flag ctf {"

看到输出里有 PK、FF D8 之类的片段，说明文件尾部还塞了别的文件，配合 010 Editor 定位偏移后 dd / WinHex 切出来。

Exif Pilot：元数据里的秘密

Exif Pilot 用来查看和编辑图片的 EXIF / IPTC / XMP 字段，界面直观，改完能直接保存。Misc 里重点看这几项：

  • Image Description / Comment / Artist —— 出题人最爱塞 base64 的地方；
  • GPS 经纬度 —— 有时是十进制度，有时要做进制转换才是真坐标；
  • 缩略图（Thumbnail） —— 主图改了但缩略图没改，原图信息藏在里面；
  • XMP 历史 —— 记录过编辑软件与修改次数，能提示"这张图被谁动过"。

命令行党用 exiftool 更全：

exiftool photo.jpg              # 全量字段
exiftool -Comment -Artist photo.jpg
exiftool -all:all -G photo.jpg  # 按分组看，方便定位 XMP/IPTC
exiftool -a -u -g1 photo.jpg    # 连隐藏/重复标签一起挖
Exif Pilot 适合"看一眼并手动改"，exiftool 适合"批量扫和写脚本"。两个都留着。

三件套检查清单

任何附件到手，我固定跑这五步：

  1. 改扩展名之前先看魔数（010 Editor）；
  2. strings -n 6 全量扫一遍，重点搜 flag、PK、-----BEGIN；
  3. 图片就查 EXIF 全字段，别漏 XMP；
  4. 文件末尾对比正确长度，多出来的字节切出来看看；
  5. 还是没线索 → 转隐写或流量那两篇的思路。
