Wireshark：拿到 pcap 先做四件事

流量题的通用开局，四步能解决大半：

  1. Statistics → Conversations：看谁在跟谁说话，异常会话（大量小包、单一端口反复连）就是主线；
  2. Statistics → Protocol Hierarchy：看协议占比，出现非 HTTP 的怪协议（ICMP 占比高、USB、802.11 探针）立刻警觉；
  3. File → Export Objects → HTTP/SMB/TFTP：题目里传输的文件直接批量导出，很多题的 flag 就在导出文件里；
  4. 搜索 flag（Ctrl+F 选 String 或 Hex）：最笨但最常中奖。

高频过滤器速查

过滤表达式用途
http.request.method == "POST"只看提交包，登录/上传题核心
urldecode(http.file_data) contains "flag"URL 解码后搜 flag
ftp || telnet || pop || imap明文协议一把抓，账号密码直接可见
icmpICMP 隧道题：看 data 段是否藏了文件
usb.capdataUSB 键盘流量：提取键值码还原输入
tcp.stream eq 3只看第 3 条 TCP 流，配合 Follow Stream
wlan.fc.type_subtype == 0x08只看 WiFi Probe 帧，隐藏 SSID 题

两个经典场景的处理：

  • USB 键盘流量：过滤 usb.capdata 导出键值十六进制，对照 USB HID usage table 写脚本还原击键（网上有现成脚本，改改就能用）；
  • ICMP 隧道：把各包 data 段按序拼起来，常是一个 base64 或一个被切开的 zip。
右键 → Follow → TCP Stream 是 Wireshark 一半的解题功能；另一半是 Export Objects。

无线流量题

pcapng 里出现 802.11 帧（有 beacon、四次握手）时，常见套路是抓包 WiFi 密码：

  1. 过滤 eapol 找到四次握手，确认握手包完整；
  2. 用 aircrack-ng capture.pcap -w dict.txt 跑字典，字典本身往往藏在题目其他附件里（EXIF、strings 输出、流量里的文件）；
  3. 拿到密码后如果还有加密数据流，Wireshark 里 Edit → Preferences → Protocols → 802.11 填入密钥解密，再走 HTTP 那套流程。

RouterPassView：路由器备份口令恢复

RouterPassView（NirSoft 出品）专门读路由器配置备份文件（.rfn、.nvram、各厂商备份格式），直接列出里面的明文/半明文口令：WiFi 密码、管理员账号、PPPoE 拨号密码。

  • 适用：Misc 题给出"路由器设置备份文件"，要求找回 WiFi 密码或管理密码——这是最短路径，不用自己解析格式；
  • 用法：打开文件即全量列出字段，Ctrl+F 搜 ssid、wpa、password；
  • 不适用：备份文件被强加密（字段全是高熵乱码）时，需要回到厂商固件逆向思路，这工具只吃"混淆"不吃"真加密"。

同类可交叉验证：路由器配置常是改名的 zip/tar，先 file 看真身，是压缩包就直接解开看 xml。
