Misc 是 CTF 里最"脏"的方向：没有固定的知识点，考的是信息收集能力 + 工具熟练度。附件可能是图片、压缩包、流量包、内存镜像，也可能是一个伪装成图片的压缩包。这篇先讲流程，工具细节在后面几篇。

Misc 到底考什么

我按解题动作把它分成六类，基本能覆盖 90% 的题目：

  • 编码转换 —— Base 家族、莫斯、脑残粉、社会主义核心价值观、进制互转，常常多层套娃；
  • 隐写 —— 位平面、LSB、GIF 帧、伪加密、附件尾部拼接、二维码；
  • 元数据与取证 —— EXIF、文件头修复、注释字段、字符串提取；
  • 流量分析 —— pcap 里的文件传输、明文口令、隐蔽信道；
  • 密码与压缩包 —— 弱口令、字典、已知明文攻击、伪加密修复；
  • 其他杂项 —— OCR、游戏存档、内存取证、音频频谱。
看到题目先别急着开工具，先问自己：这道题在"藏"什么——藏内容、藏口令，还是藏编码？

第一步：认清文件的真身

Misc 第一大坑是扩展名骗人。拿到附件先做三件事：

  1. 看文件头魔数。PNG 是 89 50 4E 47，ZIP 是 50 4B 03 04，JPEG 是 FF D8 FF，GIF 是 47 49 46 38，PCAP 是 D4 C1 / 0A 0D 0D 0A；
  2. 跑一遍 file（Linux/WSL）或直接用 010 Editor 打开看十六进制；
  3. 用 strings 粗扫一遍，很多时候 flag{ 就直接躺在里面。

如果魔数和扩展名不一致，比如一个 .jpg 开头是 50 4B 03 04，那它就是压缩包，直接改扩展名解压。

环境准备

这套工具在 Windows 上跑起来的注意点：

  • Java：StegSolve 是 .jar，需要 JRE，双击打不开就用命令行 java -jar StegSolve-1.4.jar；
  • Ruby：zsteg 是 Ruby gem，Windows 下用 RailsInstaller 装最省事，具体见压缩包那篇；
  • Python：留一个 Python 3，配合 zbar、pycryptodome、scapy 处理脚本化需求；
  • 路径：所有工具别放在带中文或空格的路径下，Java 和 Ruby 的 gem 都容易因此报错。
