什么是 ZIP 伪加密

ZIP 文件头里有个"通用标志位"（general purpose bit flag），第 0 位置 1 表示"本条目加密"。伪加密就是只把这个标志位改了，数据本身根本没加密——解压软件看到标志位就索要密码，但内容其实是明文。

识别方法：用 010 Editor 打开 zip，找到本地文件头（50 4B 03 04）后第 7-8 字节，或中央目录头（50 4B 01 02）后第 9-10 字节。如果标志位是奇数（如 01 00、09 00、99 00）而解压却能看到内容或 CRC 正常，八成是伪加密。

ZipCenOp：一键修复伪加密

ZipCenOp-x86.exe 是命令行 Java 工具，专门改中央目录的标志位：

:: 解密（把加密标志位清 0）
java -jar ZipCenOp.jar d fake.zip

:: 反过来：给压缩包加伪加密标记（自测用）
java -jar ZipCenOp.jar e plain.zip

不想装 Java 环境也可以手改：010 Editor 里把中央目录头的标志位低字节改成 00 保存即可。注意本地文件头和中央目录头两处都要改，只改一处有些解压软件仍然报错。

Advanced Archive Password Recovery：真加密怎么破

Advanced Archive Password Recovery（ARCHPR，俗称"Advanced RAR Password Recovery"同门）支持 ZIP 和 RAR 的口令恢复，界面对新手友好：

  1. File → Open Archive 载入压缩包；
  2. 攻击类型按题目线索选：Brute Force（全字符集，慢）、Mask（已知前缀/长度，如 flag{??????）、Dictionary（有字典必先用字典）；
  3. Type of attack 里选 ZIP 时留意它区分 PKZIP / WinZip AES——AES-256 基本只能爆字典，PKZIP 传统算法才有掩码暴力意义。

字典从哪来？Misc 的惯例是字典就藏在题目里：EXIF 备注、strings 输出、流量里导出的文件、甚至图片像素数。找不到字典再考虑掩码。

竞赛环境里更常用 hashcat/John 处理 AES 和 RAR5；ARCHPR 的价值是图形界面快启动，适合口令位数少的短任务。

已知明文攻击（补充武器）

题目同时给了加密 zip 和它的未加密原件（哪怕只有其中一个文件）时，用已知明文攻击恢复密钥，比爆密码快几个数量级：

bkcrack -C encrypted.zip -c secret.txt \
        -P known.zip  -p known.txt
bkcrack -C encrypted.zip -key XXXXX_XXXXX_XXXXX -unlock all.zip

要求明文与密文条目至少 12 字节对齐。bkcrack 不在本篇三件套里，但知道这条路能避免对着 AES 压缩包硬跑字典。

RailsInstaller：其实是给 zsteg 铺路

RailsInstaller 本身是 Windows 一键装 Ruby + RubyGems + DevKit + Git + SQLite 的整合包。Misc 工具箱里带它只有一个原因：zsteg 是 Ruby gem，Windows 原生没有 Ruby。

  1. 安装 RailsInstaller（一路默认，装完会生成 C:\RailsInstaller）；
  2. 打开 RailsInstaller Command Prompt（已配好 PATH）；
  3. 装 zsteg：
gem install zsteg
zsteg -a flag.png

如果 gem install 卡在 SSL 证书错误，换国内源：gem sources --add https://mirrors.aliyun.com/rubygems/ --remove https://rubygems.org/。
